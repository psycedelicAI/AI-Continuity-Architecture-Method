# Security Policy

## Scope

This repository contains a public methodology, documentation, templates,
prompts, case studies, and synthetic evaluation material related to the
AI Continuity Architecture Method.

It is not a production security system and does not contain operational
credentials, private Memory Banks, private conversations, or live system
access.

## Reporting a Concern

If you identify a security issue, privacy issue, exposed secret, or sensitive
material in this repository, please do not publish the details in a public
issue.

Instead, contact the repository owner through the private contact options
available on the GitHub profile.

Please include:

- the affected file or path;
- a description of the concern;
- the possible impact;
- steps to reproduce it, if relevant;
- a suggested remediation, if available.

## Sensitive Information

Do not submit:

- passwords;
- API keys;
- access tokens;
- private conversation content;
- personal identifiers;
- private Memory Bank material;
- operational security details;
- illegal or harmful material.

## Status

This repository is a public methodology project. Its contents are
conceptual, documentary, or experimental unless explicitly stated otherwise.
