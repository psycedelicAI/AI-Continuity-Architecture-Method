# Standard Question Sequence

> The question sequence used across the Lumo continuity test runs.

This file preserves the questions used during the continuity experiments.

The same general question sequence was used across multiple test runs in order
to make the effect of different context packages easier to observe.

The questions were not designed as a formal benchmark.

They represent a realistic working session in which the author introduces an
idea, develops it, corrects the workflow when necessary, determines where a
file belongs, and integrates it with existing project documentation.

---

## Important note

The questions are part of the test conditions.

The Memory Bank or context package is only one variable.

The prompts themselves also influence the result.

For that reason, the complete question sequence is preserved separately and
should be read together with:

- the supplied context package;
- the raw model output;
- the analysis of each test run;
- the language used during the interaction;
- any repair or follow-up prompts.

---

## Prompt language

The questions were asked in Swedish.

This means that the experiments also observed how an English-language project
context was interpreted through Swedish prompts.

The language conditions were not fully isolated in the original runs.

Future tests should record:

- prompt language;
- response language;
- document language;
- technical vocabulary;
- explicit language instructions;
- language changes during the session.
